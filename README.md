📌 Project Overview

This project documents the setup of an isolated cybersecurity lab using Oracle VirtualBox for learning cybersecurity fundamentals, network security, and ethical hacking.

The lab is intended for authorized testing, practical learning, and documenting the activities completed during my Network Walks cybersecurity internship.

🎯 Project Objectives

• Install and configure a virtual lab environment.
• Understand virtualization and virtual machines.
• Explore Kali Linux and cybersecurity tools.
• Learn basic networking and IP addressing.
• Understand isolated lab networking.
• Practice security testing only on authorized lab targets.
• Document the configuration, results, and lessons learned.

⚙️ Project Setup

Step 1: Prepare the Host

• Confirm that Windows 11 is working correctly.
• Verify that virtualization is enabled.
• Confirm that Oracle VirtualBox is installed.

Step 2: Configure the Virtual Machines

• Identify the virtual machines required by the internship.
• Download operating systems only from trusted, official sources.
• Allocate suitable RAM, CPU cores, and virtual disk space.
• Follow the course instructions for the network configuration.

Step 3: Configure Lab Networking

• Review VirtualBox network modes.
• Use an isolated Internal Network or Host-Only Network where appropriate.
• Verify connectivity only between authorized lab systems.
• Avoid bridging vulnerable machines directly onto a normal home or business network.

Step 4: Test and Document

• Record each virtual machine's configuration.
• Document network settings and observations.
• Capture screenshots of completed setup steps.
• Record errors, troubleshooting steps, and lessons learned.
